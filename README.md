# Lab Equipment Borrow System
O.5C JavaEE Final Project, 李鳌

## Introduction
This system manages lab equipment borrowing and returning.
## Environment
- JDK 1.8
- Tomcat 9
- MySQL 5.7
- Maven 3.6+
## Deploy
1. git clone this repo
2. Import sql to MySQL
3. Modify database config
4. Package to war, put into tomcat webapps
5. Start tomcat
